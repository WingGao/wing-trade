# 场外宽基基金盘中指数估算

## 目标与用户价值

为纯 A 股宽基场外开放式基金（`market="OF"`）提供手动绑定「跟踪指数或场内 ETF」参考标的的能力。用户在输入参考标的代码后，系统自动识别并实时推算基金盘中估算净值、估算涨跌幅、持仓浮盈、账户总市值、止盈目标距离及当日估算分时曲线，解决场外基金净值滞后（收盘后晚间才公布）导致的 15:00 收盘前无法决策问题。

## 已确认的上下文与约束

- **适用范围**：纯 A 股宽基指数基金（与 A 股交易日历 9:15–11:30、13:00–15:00 完全对齐，不涉及跨市场时差与汇率）。
- **绑定方式**：用户手动配置参考标的；前端只需输入代码或名称即可自动匹配标的并自动计算全部衍生数值，无需手动填复杂参数。
- **展示一致性**：绑定参考标的后的场外基金在持仓列表、看板汇总、详情页与止盈距离展示上与普通 A 股股票/ETF 保持一致，同时清晰标注「估」状态与参考来源。
- **数据安全与账本红线**：
  - 本地 `ledger.db` 不允许删除或清空数据，数据库变更必须通过 Alembic 增量迁移完成。
  - 行情与估算值均为派生展示数据，不得覆盖官方已公布净值缓存，不得改写或阻塞账务事实。
  - 全部金额、价格、份额、涨跌幅与仓位系数统一使用 `Decimal` 精确计算。

## 功能需求

### R1. 场外基金绑定跟踪参考标的
- 仅场外基金（`market="OF"`）支持配置参考标的（`proxySymbol`、`proxyName`、`trackingRatio`）。
- 支持绑定 A 股宽基指数（如 `SH:000300` 沪深300、`SH:000905` 中证500、`SH:000852` 中证1000、`SH:000016` 上证50、`SZ:399006` 创业板指、`SH:000688` 科创50 等）或对应的 A 股场内 ETF（如 `SH:510300`）。
- 仓位系数 `trackingRatio` 默认为 `0.95`（区间 `(0, 1.5]`），作为可选微调项；用户只输入并选择代码即可直接保存生效。
- 支持随时修改或清除（解绑）参考标的；清除后立即恢复为纯官方净值展示。

### R2. 证券查名与 A 股指数实时行情/分时支持
- `/api/v1/securities/lookup` 支持按 6 位代码或中文名称检索常见 A 股宽基指数（如 `000300`、`399006`、`沪深300`），并正确识别市场（`SH`/`SZ`）与类型（`INDEX`）。
- A 股批量行情源（`EastmoneyQuoteProvider`）与分时接口（`SecurityInfoProvider._intraday_eastmoney`）支持读取已绑定 A 股指数的实时点位、昨收、涨跌幅、报价时间与当日分钟分时序列。

### R3. 盘中估算净值计算与自动日期对齐
- 当场外基金已绑定 `proxySymbol`，且同时具备有效的基金最新已公布官方净值（`officialNav`、`officialNavDate`）与参考标的当日实时行情（`proxyChangePct`、`proxyTradingDate`）时：
  - 若 `officialNavDate < proxyTradingDate`（盘中或刚收盘、今日官方净值尚未公布）：
    - $\text{估算涨跌幅} = \text{proxyChangePct} \times \text{trackingRatio}$
    - $\text{估算净值} = \text{officialNav} \times (1 + \text{估算涨跌幅} / 100)$
    - 输出报价中 `lastPrice = 估算净值`、`prevClose = officialNav`、`changePct = 估算涨跌幅`、`sourceTime = 参考标的报价时间`、`isEstimated = true`，并附带 `officialNav`、`officialNavDate`、`proxySymbol`、`proxyName`、`proxyChangePct`、`trackingRatio`。
  - 若 `officialNavDate >= proxyTradingDate`（今日官方净值已公布）：
    - 自动切回官方已公布净值（`isEstimated = false`），严禁重复叠乘今日涨跌幅。
  - 若参考标的行情不可用或过期：
    - 平滑降级回基金自身最新已公布官方净值，不生成零价或伪造价格，且不阻断页面展示。

### R4. 与股票一致的看板、持仓、批次与止盈体验
- 看板（`/api/v1/dashboard`）、持仓批次（`/api/v1/securities/{id}/lots`）与报价查询（`/api/v1/quotes`）统一基于估算后的快照计算单只持仓市值、未实现盈亏、收益率、最低价组指标与账户总估值。
- 盘中交易时段内，绑定参考标的的场外基金随 A 股正常轮询刷新（看板 10s、详情页 3s）。
- 止盈目标：前端与看板基于当前展示价格（盘中为估算净值）实时呈现距止盈目标价的差值并在达标时高亮提示；数据库 `ProfitTarget.status = TRIGGERED` 仅在**官方已公布净值**达标时固化，避免盘中冲高回落误触发。

### R5. 详情页当日估算分时图与历史净值切换
- 当已绑定参考标的的场外基金处于 `officialNavDate < 今日` 且参考标的有当日分时序列时，`/api/v1/securities/{id}/intraday` 返回按公式换算后的当日估算净值分钟序列（`seriesKind = "estimated_intraday"`），纵轴直接展示估算净值，前端图表交互与股票当日分时一致。
- 同时保留查看近 30 日历史官方净值曲线的能力（通过查询参数或前端切换按钮查看 `seriesKind = "nav"`）。

### R6. 前端配置与视觉标识
- 场外基金详情页提供简洁的「跟踪标的」配置入口：输入代码/名称自动下拉候选，选中后一键保存（仓位系数默认 `0.95` 可选展开微调），保存后立即刷新价格、盈亏与图表。
- `QuoteBadge` 及持仓/详情页对 `isEstimated = true` 的报价展示明确的 `估` 标签，并在提示信息中展示参考标的名称、实时涨跌幅、仓位系数及昨日官方净值。

## 验收标准

- [ ] **AC1（绑定与校验）**：可为场外基金绑定 A 股指数或场内 ETF，输入 `000300` / `510300` 能自动查到名称与市场并保存，默认 `trackingRatio = 0.95`；支持修改与解绑；非 `OF` 证券调用绑定接口返回明确业务校验错误。
- [ ] **AC2（精确估算与防重算）**：在官方净值日期早于参考标的交易日时，估算净值与估算涨跌幅满足 `Decimal` 精确公式；当官方净值更新至当日后，自动切换为官方净值且 `isEstimated = false`。
- [ ] **AC3（一致估值与轮询）**：看板持仓行、账户汇总、详情页批次浮盈与止盈距离均自动采用盘中估算净值；盘中交易时段详情页与看板正常自动刷新；参考标的行情失败时平滑回退至官方净值。
- [ ] **AC4（估算分时与历史切换）**：已绑定参考标的的场外基金盘中在详情页展示当日估算净值分时图，并可切换查看近 30 日官方净值曲线。
- [ ] **AC5（止盈不误固化）**：盘中估算净值触达止盈价时，前端明确高亮提示预估达标，但数据库 `ProfitTarget.status` 不被盘中估算改写为 `TRIGGERED`。
- [ ] **AC6（迁移与测试）**：Alembic 迁移平滑升级且不破坏现有 `ledger.db` 数据；后端单测/集成测试、前端类型检查与构建、相关测试全部通过。

## 非本阶段范围（Out of Scope）

- 美股、港股、商品等 QDII 跨市场基金的跨时区/汇率估算。
- 自动爬取基金 F10 档案自动推断跟踪标的（本阶段坚持用户手动输代码选择）。
- 接入第三方天天基金 `fundgz` 盘中估值接口作为兜底。
- 盘中自动邮件/推送告警（保留在现有看板/详情页展示）。
