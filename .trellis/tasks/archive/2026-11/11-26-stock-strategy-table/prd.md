# 个股详情页策略表与 Markdown 导入

## 目标与用户价值

在个股详情页（包含独立详情页与首页桌面端右栏内嵌详情）中新增**买卖策略表**模块，帮助用户将外部 AI 生成或自行规划的分批/网格买卖计划结构化沉淀在对应标的页面中。用户既可以通过粘贴 Markdown 表格快速批量导入，也可以在页面上直接维护单行档位、标记执行状态，并通过一键复制固定 AI 提示词快速让外部 AI 生成可直接解析的标准表格。

## 背景与已确认仓库事实

- **前端复用结构**：个股详情核心面板位于 `frontend/src/components/SecurityDetailPanel.vue`，同时被独立详情页 `frontend/src/pages/SecurityDetailPage.vue` 与总览页桌面端右栏 `frontend/src/pages/DashboardPage.vue`（`embedded=true`）复用。
- **双端布局规范**：`SecurityDetailPanel.vue` 按 `768px` 断点拆分桌面端（Element Plus 卡片与表格）与移动端（高信息密度紧凑卡片 `.m-section`）。
- **后端存储与迁移**：后端采用 FastAPI + SQLAlchemy + SQLite（`ledger.db`），启动时通过 `backend/app/db/migrations.py` 中的 `prepare_database_schema` 执行 Alembic 增量迁移（当前最新版本为 `0008_watchlist_buyback_alerts.py`），并基于 `user_id` 做多用户数据隔离。
- **数据安全红线**：本地 `ledger.db` 严禁删除或清空数据，新增结构必须采用向后兼容的增量建表迁移。

## 功能需求

### R1. 策略表数据模型与归属维度

- 策略表持久化在后端 SQLite（`ledger.db`）中，按 **`用户 + 标的`（`user_id + security_id`）** 维度隔离与共享：
  - 同一用户在任意账户下查看同一只标的时看到同一份策略表；
  - 即使当前币种尚未创建账户或该标的暂无持仓，也能正常查看、导入和维护策略表；
  - 不同用户之间数据完全隔离。
- 采用**买卖配对档位行**模型，每行包含以下字段：
  - `buyPrice`（买入价，可选高精度十进制数，> 0）
  - `buyQty`（买入数量，可选高精度十进制数，> 0）
  - `sellPrice`（卖出价，可选高精度十进制数，> 0）
  - `sellQty`（卖出数量，可选高精度十进制数，> 0）
  - `note`（备注，可选文本）
  - `status`（执行状态，枚举：`PENDING` 待执行 / `BOUGHT` 已买入 / `COMPLETED` 已完成，默认 `PENDING`）
  - `sortOrder`（展示顺序，按导入顺序或新增顺序排列）
- 单行约束：买入侧与卖出侧允许其中一侧留空（兼容单边买入或单边止盈档位），但每行至少需填写一个有效价格或数量（不允许全空行）。

### R2. 个股详情页策略表展示与现价参考

- 在 `SecurityDetailPanel.vue` 中新增策略表区域（位于持仓批次卡片下方，桌面端与移动端均适配）：
  - **桌面端**：以卡片 + 表格展示序号、买入价、买入数量、卖出价、卖出数量、状态（可快捷切换）、备注及行操作（编辑、删除）；顶部操作区提供「导入 Markdown」、「新增档位」、「AI 提示词」、「清空」按钮。
  - **移动端（≤ 768px）**：遵循高信息密度紧凑卡片规范（零横向溢出），每档展示买卖价格与数量、状态标签/切换、备注与紧凑编辑/删除操作。
- **现价轻量参考**：当标的已有实时行情现价（`currentQuote.lastPrice`）时：
  - 对状态为 `PENDING` 且 `现价 <= 买入价` 的档位给予买入触达高亮提示；
  - 对状态为 `PENDING` 或 `BOUGHT` 且 `现价 >= 卖出价` 的档位给予卖出触达高亮提示。
- 空态展示：当该标的暂无策略行时，展示简洁空态引导，可直接点击「导入 Markdown」、「复制 AI 提示词」或「新增档位」。

### R3. Markdown 表格与 CSV 文本导入解析

- 点击「导入 Markdown/CSV」打开导入弹窗，用户粘贴包含 Markdown 表格或 CSV/TSV 的文本（允许前后混杂 AI 的说明文字或代码块包裹，解析器优先提取首个有效 Markdown 表格，未命中时自动按 CSV/TSV 解析，兼容带表头与无表头 4~5 列纯数据）。
- 解析规则：
  - 识别常见中文/英文表头别名，自动映射列：
    - 买入价：`买入价` / `买价` / `买入价格` / `目标买价` / `buy price` / `buy_price`
    - 买入数量：`买入数量` / `买量` / `买入股数` / `买入份额` / `buy qty` / `buy_qty`
    - 卖出价：`卖出价` / `卖价` / `卖出价格` / `目标卖价` / `sell price` / `sell_price`
    - 卖出数量：`卖出数量` / `卖量` / `卖出股数` / `卖出份额` / `sell qty` / `sell_qty`
    - 备注：`备注` / `说明` / `档位` / `条件` / `原因` / `note` / `memo` / `remark`
    - 状态（可选）：`状态` / `执行状态` / `status`（默认 `待执行`）
  - 若表格没有匹配到已知列名但列数为 4~5 列，提供合理的按位置回退映射（买入价、买入数量、卖出价、卖出数量、[备注]）并在预览区明确展示解析结果供用户确认。
  - 自动清洗常见格式字符：货币符号（`¥`、`$`、`￥`）、千分位逗号（`,`）、单位后缀（`股`、`份`）、Markdown 加粗符号（`**`）以及空占位符（`-`、`—`、`无`、`N/A` 识别为空）。
- 导入前实时预览解析后的结构化行列表与异常行提示（列出无法解析的单元格或非法数值行号），异常未修复时阻止提交或明确提示。
- 导入模式支持用户选择：**覆盖当前策略表（默认）** 或 **追加到末尾**。

### R4. 行级手动维护与状态管理

- **新增档位 / 编辑档位**：通过统一弹窗新增或修改单行的买入价、买入数量、卖出价、卖出数量、执行状态与备注，前端与后端均校验数值合法性（非负、正数约束与非全空行约束）。
- **快捷切换状态**：在策略表行内可直接将执行状态切换为「待执行 / 已买入 / 已完成」，立即落库保存。
- **删除单行 / 清空全部**：支持删除单行及一键清空当前标的策略表（清空需二次确认）。

### R5. 固定 AI 提示词展示与一键复制

- 提供**完全固定的纯静态 AI 提示词**（不随标的代码、名称或现价动态拼接），内容明确要求 AI 输出包含 `买入价 | 买入数量 | 卖出价 | 卖出数量 | 备注` 五列的标准 Markdown 表格、纯数字格式规范及单边留空写法。
- 入口位置：
  - 策略表头部工具栏提供「复制 AI 提示词」按钮（点击直接复制，并支持点击查看/预览完整提示词内容）；
  - Markdown 导入弹窗内同样提供一键复制与展开查看入口，方便用户边导边用。
- 复制后给出明确成功提示；若浏览器剪贴板 API 不可用，自动降级使用 `textarea` + `execCommand('copy')` 或提供选中复制兜底。

## 明确非范围项（Out of Scope）

- 不打通“点击策略行自动预填并打开录入买入/卖出配对弹窗”的交易联动（后续如有需要再扩展）。
- 不新增企微/邮件到价推送提醒（仅在详情页内做视觉高亮参考）。
- 不修改现有 `Strategy`（持仓策略分组）、`Lot`（持仓批次）、`Trade`（交易流水）及 `WatchlistItem`（关注表）的数据结构与计算逻辑。
- 不做策略历史版本管理、多套命名方案切换或策略回测统计。

## 验收标准

- [ ] 数据库通过 Alembic 增量迁移 `0009_security_strategy_rows` 创建新表，启动不破坏既有 `ledger.db` 数据，且按 `user_id + security_id` 严格隔离。
- [ ] 在独立个股详情页（`SecurityDetailPage`）与首页右栏内嵌详情（`DashboardPage`）中均可展示并操作策略表；切换同币种不同账户时，同一标的展示同一份策略表。
- [ ] 粘贴标准 AI 生成的 Markdown 表格（含前后说明文字、货币符号、千分位、单边空值、备注列）可正确解析预览并导入保存，刷新页面后数据持久化保留。
- [ ] 粘贴非法文本或包含无效数值（如负数、非数字价格）的表格时，预览区给出清晰的错误提示且不写入脏数据。
- [ ] 支持覆盖替换与追加两种导入模式，支持单行新增、编辑、删除、快捷切换执行状态（待执行/已买入/已完成）以及二次确认清空策略表。
- [ ] 存在实时现价时，触达买入价（待执行）或触达卖出价（待执行/已买入）的档位在策略表中呈现清晰高亮提示。
- [ ] 策略表头部及 Markdown 导入弹窗均提供固定 AI 提示词的一键复制与全文预览，复制出的提示词在不同个股页完全一致且可直接指导 AI 输出兼容解析器的 Markdown 表格。
- [ ] 桌面端与移动端（≤ 768px）均无横向溢出，布局整洁可用。
- [ ] 后端单元测试与 API 集成测试通过，前端 TypeScript 类型检查与构建通过，Markdown 解析工具单元测试通过。
