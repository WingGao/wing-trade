# 需求文档：支持场外开放式基金简单买卖与已公布净值

## 1. 背景与目标

当前账本已支持沪深北 A 股（`SH` / `SZ` / `BJ`）与美股（`US`）的批次记账、卖出配对和行情估值。用户需要把日常持有的**场外开放式公募基金**纳入同一账本，完成简单的买入（申购确认）与卖出（赎回确认）记账，并在首页和详情页查看基于**最新已公布单位净值**的持仓估值与**近期历史净值走势**。

## 2. 需求范围（MVP）

### 2.1 在范围内
1. **场外基金查找与建档**
   - 支持通过 6 位基金代码或基金名称在外部查名接口检索场外开放式基金。
   - 支持在外部查名不可用时，手动选择“场外基金（`OF`）”新增标的。
   - 场外基金使用人民币（`CNY`）账户记账，可与 A 股共享同一 `CNY` 账户。
2. **简单买卖记账与批次配对**
   - 用户在份额确认后，按“确认份额（支持小数）+ 单位净值（支持 4 位小数）+ 申购/赎回费 + 成交时间”录入买入或卖出。
   - 复用现有批次配对（FIFO / LIFO / EQUAL / 手动）、交易编辑、交易撤销、重算及止盈目标体系。
3. **最新已公布单位净值行情**
   - 仅采用**最新已公布单位净值（NAV）**作为场外基金行情价格（不使用盘中估算净值）。
   - 首页总览、持仓浮盈、最低价批次合计、止盈提醒与自选行情统一接入该净值；行情不可用时保留历史缓存并标为过期，不阻塞记账。
4. **详情页近期历史净值曲线**
   - 场外基金详情页展示**近期已公布单位净值走势图**（最近约 30 个净值日），不展示日内分时图，也不发起 3 秒高频轮询。
5. **前端展示精度与单位适配**
   - 场外基金份额展示 2~4 位小数（股票保持整数），单位显示“份”（股票保持“股”）。
   - 场外基金净值及含费单位成本展示 4 位小数。

### 2.2 不在范围内（明确排除）
- 按金额申购与 T+1 在途待确认订单状态机。
- 现金分红、红利再投资等独立分红流水事件类型。
- 基金持有天数阶梯赎回费率自动计算。
- 场外美元基金（QDII 美元份额）或多币种换汇。

## 3. 约束与非功能要求

- **零破坏性变更**：不得修改、删除或清空本地 `ledger.db` 既有数据；不要求新增数据库迁移即可兼容现有表结构。
- **精确数值**：所有份额、净值、金额与涨跌幅严格使用精确十进制（`Decimal`），禁止二进制浮点进入账务和行情解析。
- **隔离性**：场外基金行情失败不得阻塞账务读写，也不得污染 A 股或美股的既有行情缓存与刷新逻辑。
- **中文文档与注释**：所有规划文档、规范文档和方法注释均使用中文。

## 4. 验收标准

1. **查名与建档**：输入场外基金代码/名称（如 `005827`）可查到 `OF:005827` 且标记为 `FUND`；手动选择“场外基金”新增后，`market="OF"`、`securityType="FUND"`、`currency="CNY"`。
2. **小数份额买卖**：可在 `CNY` 账户对 `OF` 基金录入小数份额（如 `1234.56` 份）与四位净值（如 `1.8234` 元）的买入与卖出配对，后端核算守恒，前端总览、详情页、批次表、已结清明细与流水页正确显示小数份额、4 位净值及“份”单位。
3. **已公布净值估值**：`EastmoneyFundQuoteProvider` 正确解析最新已公布单位净值、前一日净值与日涨跌幅，写入共享 `quote_cache`，并在 `Dashboard` 中参与市值与浮盈计算；场外基金缓存不会在盘中按分钟级误判为过期。
4. **近期净值曲线**：访问 `GET /api/v1/securities/{id}/intraday` 时，场外基金返回 `seriesKind="nav"` 与按日期升序排列的近期净值点，前端以 `MM-DD` 横轴和 4 位净值纵轴绘制，且详情页不开启 3 秒轮询。
5. **回归与质量门禁**：后端 `ruff`、`mypy`、`pytest` 全部通过；前端 `pnpm run type-check` 与 `pnpm run build` 全部通过；现有 A 股和美股功能与单测无回归。
