# 持仓批次表格列合并与快捷卖出

## 背景与目标

个股/基金详情页中的「持仓批次」桌面端表格原有 10 列，横向过宽且信息分散；同时用户在查看单个批次后需要手动输入剩余股数/份额到卖出弹窗。

本任务目标：
1. 将持仓批次桌面端过宽的数值列合理合并为「一列多行」展示，减少横向滚动并保持信息清晰可读（并非全部合并为一列）。
2. 将「浮盈 / 收益率」与「止盈目标」合并展示，并增加批次级「卖出」快捷入口，点击后自动将本批次剩余股数/份额填入卖出弹窗。

## 需求范围

1. **列合并（桌面端 `LotTable.vue`）**：
   - 将原「初始股数/份额」「剩余股数/份额」「含费单位成本」合并为 **股数 / 单位成本**（基金显示 **份额 / 单位成本**），一列两行：首行展示 `剩 X / 初 Y`，次行展示 `含费单价`。
   - 将原「成本总价」「现值 / 现价（净值）」合并为 **成本 / 现值**，一列两行：首行展示当前成本总价（部分卖出时附带初始成本），次行展示现值及现价/净值（缺失行情或已结清展示 `现值 —`）。
   - 将原「浮盈 / 收益率」「止盈目标」合并为 **浮盈 / 止盈目标**，首行展示浮盈与收益率（保留红涨绿跌样式），下方展示批次止盈或继承止盈信息及「预估达标」标签。
   - 新增独立 **操作** 列，针对持有中（`OPEN`）批次提供 **卖出** 与 **设置** 按钮；已结清批次展示 `—`。
2. **移动端同步支持快捷卖出**：
   - 移动端批次卡片头部在持有中批次增加 **卖出** 按钮，与 **设置** 按钮并列。
3. **卖出弹窗数量预填（`SecurityDetailPanel.vue` + `SellMatchDrawer.vue`）**：
   - 点击批次行的 **卖出** 按钮时，打开 `SellMatchDrawer`，自动将本批次 `remainingQty` 填入卖出数量/赎回份额输入框，并去除小数末尾冗余零（纯字符串处理，不经浮点转换）。
   - 点击页面顶部工具栏的 **卖出配对** 按钮时，清空预填数量，不影响原有手动输入流程。
   - 不改变既有后端接口与卖出预览/提交契约。

## 验收标准

- [ ] 桌面端 `LotTable` 列数精简，原 5 个数量/成本/现值列合并为 2 列多行展示，浮盈与止盈目标合并展示，操作列提供「卖出」「设置」。
- [ ] 浮盈与收益率在合并列中仍正确应用红涨绿跌颜色（不被主文本色覆盖）。
- [ ] 点击持有中批次的「卖出」按钮，打开卖出配对抽屉并自动填入该批次剩余股数/份额（去除冗余尾零）。
- [ ] 点击顶部「卖出配对」按钮，打开抽屉时不会残留上一次点击批次卖出带入的数量。
- [ ] `cd frontend && pnpm run type-check && pnpm run build` 通过。
- [ ] 所有新增方法均有中文注释，相关前端契约文档同步更新。
