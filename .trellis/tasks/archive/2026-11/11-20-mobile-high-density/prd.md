# 前端移动端高信息密度适配 PRD

## 1. 背景与目标

当前前端（`frontend/`）仅面向桌面宽屏设计（`body` 最小宽度 1080px，固定 220px 左侧导航栏与多列宽表格），在手机浏览器中无法正常浏览与操作。

本任务目标是在**现有前端项目内**新增面向手机浏览器的高信息密度视图，让用户可以在手机竖屏下高频、高效地查看持仓与收益、查看个股分时与批次、完成买卖记账及流水复盘，同时保持桌面端体验与既有契约零破坏。

## 2. 范围定义

### 2.1 范围内（全部业务功能，除管理页）
1. **全局应用外壳与导航**（`App.vue`、`styles.css`）：移动端极简顶栏 + 底部固定 TabBar。
2. **登录页**（`LoginPage.vue`）：手机竖屏表单与间距适配。
3. **总览页**（`DashboardPage.vue`）：
   - 顶部紧凑状态与操作条（估值状态、全局止盈、显示已结清、刷新行情）；
   - 紧凑账户汇总网格；
   - 紧凑快速记账搜索栏（选中证券后展开账户与买卖/新增操作）；
   - **活动仓位高密度列表（全展开模式）**：每行默认常驻核心 3 列数据 + 底部次级信息栏（最低价批次合计、策略回本参考价、待核算刷新入口），支持点击表头切换当前涨幅排序；
   - 自选股行情 2 列紧凑网格。
4. **个股详情页**（`SecurityDetailPage.vue`）：
   - 紧凑头部与快捷操作栏（账户切换、买入、卖出配对、全局/个股止盈）；
   - 自适应宽度日内分时图（`IntradayChart.vue`）；
   - 紧凑 2x2 持仓汇总；
   - 持仓批次高密度列表（`LotTable.vue`）；
   - 已结清买卖明细高密度列表（`SettledTradeTable.vue`）。
5. **交易流水页**（`TradesPage.vue`）：方向筛选 + 紧凑流水列表（保留编辑、撤销操作）。
6. **复盘分析页**（`AnalyticsPage.vue`）：紧凑 2x2 指标 + 交易周期紧凑列表。
7. **所有业务弹窗与抽屉**：
   - `BuyTradeDialog.vue`（买入记账）
   - `SellMatchDrawer.vue`（卖出配对工作台及配对预览列表）
   - `EditTradeDialog.vue`（编辑交易流水）
   - `ProfitSettingDialog.vue`（全局/个股止盈设置）
   - `ProfitTargetDialog.vue`（批次止盈目标设置）

### 2.2 范围外
- 管理员用户管理页（`AdminUsersPage.vue`）不做移动端专项适配。
- 不打包原生 App、不做小程序、不新增后端接口或修改账务计算规则。

## 3. 核心需求与约束

1. **纯上下滚动，零横向滚动**：在常见手机竖屏宽度（360px ~ 430px）下，所有范围内页面与弹窗均不得出现页面级或主列表级横向滚动条。
2. **高信息密度**：
   - 活动仓位采用**全展开模式**，每行直接展示完整核心信息（证券名/代码、持股/成本、总价值/现价/涨跌/报价状态、浮盈/收益率、最低价批次合计、策略回本参考价），无需点击展开；
   - 通过紧凑字号、极小内边距、1px 细分割线和等宽数字（`tabular-nums`）提升单屏可读条数。
3. **账务与行情契约不退化**：
   - 严禁在前端重算账务或盈亏，所有核心数值沿用后端返回值；
   - 报价过期/不可用必须保留明确文字提示，不得仅靠颜色表达，且行情失败不得阻塞账务操作；
   - 保留所有既有交互安全机制（卖出必须先预览且输入变更失效、撤销需二次确认、编辑保留原始字符串精度与 revision、重算范围防重与代次防护）。
4. **桌面端零破坏**：桌面端（`> 768px`）保持现有布局、样式、DOM 结构和全部既有 Playwright E2E 用例通过。

## 4. 验收标准

- [ ] 在手机视口（如 `390x844` 与 `360x780`）下，登录、总览、个股详情、交易流水、复盘分析及全部业务弹窗/抽屉均无横向溢出（`document.documentElement.scrollWidth <= window.innerWidth`）。
- [ ] 总览页活动仓位在手机端以高密度列表展示，默认按当前涨幅降序，点击排序头可切换升降序，无行情持仓始终排末尾，每行常驻最低价批次合计与策略回本参考价。
- [ ] 个股详情页在手机端完整展示分时图、4 项持仓汇总、全部持仓批次（含止盈设置入口）及开启“显示已结清”后的已结清买卖明细。
- [ ] 手机端可完整走通快速记账查找证券 -> 买入记账 / 卖出配对预览与确认、编辑交易、撤销交易、设置三级止盈目标。
- [ ] 桌面端全部既有 Playwright E2E 用例、新增移动端 Playwright E2E 用例、`pnpm run type-check` 与 `pnpm run build` 全部通过。
