## 实施顺序

1. **行情源与缓存**
   - 新增有调用边界、可注入测试传输的东方财富批量行情提供者，加入经校验的真实／模拟配置，不在导入时联网，也不新增 SDK 依赖。
   - 保留 JSON 精确十进制数值、市场标识、报价／获取时间，并妥善处理无效行和缺失行。
   - 复用共享采集器节流／退避，保留最后有效价格，对请求范围内遗漏项标记过期，部分成功后返回完整缓存范围。
   - 测试批量请求、无效价格、字段缺失、超时、不支持的市场、并发、熔断，以及只有有效行情才能触发目标提醒。
2. **后端估值与读取模型**
   - 增加 Decimal 浮盈率计算，以及同一账户／证券／策略内最低买入价所有批次的合计。按原始成交价分组，按剩余数量／成本估值，不从同价批次中只取一批。
   - 增加确定性用例：多个同价批次、不同买入费用、部分卖出、其中一批结清／作废、最低价全部批次结清，以及其他账户／策略存在同价批次。
   - 使用固定行情快照映射构建一致的首页 DTO，落实 cache／auto／manual 模式。只提取必要的共享读取逻辑，保留现有接口。
   - 测试完整／过期／部分缺失／全部不可用／空持仓汇总、零值／负值、includeClosed、账户／币种边界及交易后的估值变化。
3. **前端接入**
   - 增加共享 DTO、类型化首页 API 方法和整份估值同步加载，保持现有页面兼容。
   - 实现首次加载、定时／手动刷新、页面隐藏／可见和卸载的无重叠请求管理，增加旧响应保护，交易后保留 includeClosed 并重载。
   - 扩展持仓表，显示持仓和最低价批次组的浮盈金额／百分比，并展示共同买入价、批次数和合计剩余数量。
   - 保持价格与浮盈一致，显示报价／获取时间、过期／错误／覆盖状态，区分 null 和零。保留当前页面结构和快速记账。
4. **验证、文档与评审**
   - 为新首页接口、同最低价合并、轮询、降级和交易后重载增加可控的 Playwright 数据与场景。
   - 说明行情源配置、成本口径、轮询间隔与上游延迟的区别，以及离线回退方式。本任务新增或更新的说明文档使用中文，程序标识保留原文。
   - 执行整个任务范围的质量检查，派发 Trellis 检查代理，修复确认的问题；提出提交方案前，评估是否需更新可执行规范。
