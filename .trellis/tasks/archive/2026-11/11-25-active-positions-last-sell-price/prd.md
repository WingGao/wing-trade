# 活动仓位与详情页增加上次卖出价并对齐双端展示

## 1. 目标与用户价值

参考 `docs/image.png` 的高信息密度展示结构，为活动仓位与个股详情页补充“上次卖出价（上卖）”及其相对现价的涨跌幅，统一 PC 端与移动端的活动仓位展示体验，并在 PC 端利用右侧空余空间直接联动展示当前选中个股的详情页。用户在盯盘、波段加减仓与网格回补时，可在一个视野内快速对比“现价、最低价批次（低批）、上次卖出价（上卖）”，并通过筛选与多维度排序快速定位目标持仓。

## 2. 需求范围（In Scope）

### R1. 上次卖出价数据与实时派生契约
- **统计口径**：在当前账户 + 证券 + 策略范围内，取全部历史有效卖出交易（`Trade.side == "SELL"` 且 `Trade.status == "ACTIVE"`）中最近一笔的原始成交价 `price`（排序键：`executed_at DESC, created_at DESC, id DESC`），不限当前持仓周期（跨 `Cycle` 有效）。
- **相对涨跌幅**：存在上次卖出价且存在有效正现价时，计算 `(现价 - 上次卖出价) / 上次卖出价 × 100%`（百分比单位，保留 6 位小数供前端格式化为 2 位小数并带正负号）。
- **无卖出记录**：返回 `lastSellPrice = null`、`lastSellExecutedAt = null`、`vsLastSellPct = null`；界面上卖价格列展示 `暂无卖出`，涨跌幅列展示 `—`。
- **后端接口**：
  - `GET /api/v1/dashboard`（`backend/app/api/schemas/dashboard.py`、`backend/app/services/dashboard.py`）：`DashboardPositionRead` 新增 `lastSellPrice`、`lastSellExecutedAt`、`vsLastSellPct`。
  - `GET /api/v1/securities/{security_id}/lots`（`backend/app/api/v1/router.py`）：`summary` 新增 `lastSellPrice`、`lastSellExecutedAt`、`vsLastSellPct`（或在顶层同步提供，前端统一从 `summary` 读取）。
- **SSE 实时推流派生**：`frontend/src/utils/valuation.ts` 中的 `projectDashboardWithQuotes()` 与 `projectLotsWithQuote()` 在收到新实时报价时，使用 `BigInt` 精确十进制同步重算 `vsLastSellPct`，不修改 `lastSellPrice` 账务事实。

### R2. 双端统一的活动仓位列表（对齐 `docs/image.png`）
- 抽取共享组件 `ActivePositionList.vue`，供 PC 端与移动端复用，消除两套割裂的活动仓位展示：
  - **头部**：`活动仓位` + `N 个未结清持仓`，右侧提供 `紧凑` 视图切换按钮（在标准/紧凑行高之间切换）。
  - **筛选标签 + 搜索栏**：
    - 筛选标签（带实时数量角标）：`全部` | `低批盈利`（`lowestPriceGroup.unrealizedPnl > 0`）| `低于上卖`（有有效现价和上次卖出价且 `现价 < 上次卖出价`，即 `vsLastSellPct < 0`）| `浮亏仓位`（`unrealizedPnl < 0`）。
    - 本地搜索框：`代码 / 名称`（按证券代码、市场:代码或名称不区分大小写实时过滤）。
  - **表头（3 列，5 个可正反排序维度）**：
    - 左列：`证券 / 持仓`
    - 中列：`总市值 / 浮盈`（点击「总市值」按总市值 `remainingQty * lastPrice` 正反排序；点击「浮盈」按持仓浮盈额 `unrealizedPnl` 正反排序）
    - 右列：`现价 · 低批 · 上卖`（三个标题均可独立点击正反排序：「现价」按当日涨跌幅 `quote.changePct`、「低批」按现价相对最低价批次涨跌幅 `lowestPriceGroup.unrealizedReturnPct`、「上卖」按现价相对上次卖出价涨跌幅 `vsLastSellPct`）
    - **默认排序**：按「现价（当日涨跌幅）」降序；点击当前激活排序项在降序/升序间切换（不出现“取消排序”第三态），点击新排序项切至该项降序；任何排序维度下，缺失值（无行情、无低批或无上卖）始终排在末尾。
  - **每行 3 列结构**：
    - 左列：证券代码（蓝色加粗） / 证券名称（粗体） / 持仓股数与加权均价（如 `100股 · 均 ¥252.80`；基金为 `份`、4 位净值）。
    - 中列（右对齐）：总市值（大号粗体，缺行情显示 `—`） / 总浮盈额 + 总浮盈率（红涨绿跌） / 低批剩余数量 · 低批浮盈额（如 `低批 100股 · +¥360.00`，无低批时显示 `无低批`）。
    - 右列（左侧细竖线分隔，三行对齐）：
      - `现价` | 最新价（股票 3 位 / 基金 4 位） | 当日涨跌幅（带符号，悬停可查看报价状态与来源/时间；异常状态如过期/估算/盘前/盘后/不可用保留紧凑标识）
      - `低批` | 最低价批次买入价 | 现价相对低批涨跌幅
      - `上卖` | 上次卖出价（无则 `暂无卖出`） | 现价相对上卖涨跌幅（无则 `—`）
  - **待核算刷新**：当 `row.needsRefresh === true` 时，在行内保留紧凑的“待刷新 / 刷新持仓”入口，沿用既有确认、防重与服务端重读契约。

### R3. PC 端左右分栏联动展示个股详情
- **首页（`DashboardPage.vue`）PC 端**：活动仓位区块采用左右分栏（Master-Detail）：
  - 左侧：统一的活动仓位列表（固定/自适应合理宽度，确保三列信息不挤压、无横向溢出）。
  - 右侧：空出区域直接内嵌展示当前选中持仓的个股详情面板（复用抽取的 `SecurityDetailPanel.vue`，含分时图、持仓汇总、批次表、已结清买卖明细、快捷买卖/止盈/重算操作，以及“独立页打开”入口）。
  - 默认选中当前排序下的第一个活动持仓；点击左侧任意仓位立即在右侧切换；当无活动持仓时右侧展示清晰空态引导。
  - 左侧仓位列表中的交易写入（快速记账）或右侧详情内的买卖/止盈/重算操作完成后，同步刷新账务快照与当前选中详情。
- **独立个股详情页（`SecurityDetailPage.vue`）**：
  - PC 端：左侧活动仓位快速切换栏对齐新的活动仓位列表组件（支持筛选、搜索、排序与三列参考价展示），右侧为主详情面板（与首页右栏共用同一组件）。
  - 移动端：保持 `<= 768px` 零横向溢出；顶部活动仓位切换条同步支持展示/感知上次卖出价状态，详情页持仓汇总区新增“上次卖出价”指标项（含相对现价涨跌幅，无卖出则显示 `暂无卖出`）。
- **详情页持仓汇总区**：PC 端与移动端均在原有 4 项（总持股数/总份额、持仓成本、已实现收益、总浮盈）基础上新增“上次卖出价”展示项（显示上次卖出价、相对现价涨跌幅及可选成交日期提示，策略回本参考价可作为辅助信息保留不丢失）。

## 3. 明确不在范围内（Out of Scope）

- 不修改数据库表结构（不新增 Alembic 迁移），不删除或清空本地 `ledger.db` 数据。
- 不改变 `Trade` / `Lot` / `TradeMatch` 的既有撮合、重算、止盈计算规则。
- 不调整交易流水页（`TradesPage.vue`）、复盘分析页（`AnalyticsPage.vue`）与用户管理页（`AdminUsersPage.vue`）。
- 不引入后端排序或后端筛选参数（筛选与排序均基于单次一致快照在前端完成）。

## 4. 验收标准

- **AC1（后端数据口径）**：存在多轮周期有效卖出时，`GET /api/v1/dashboard` 与 `GET /api/v1/securities/{id}/lots` 返回当前账户 + 证券 + 策略下最近一笔 `ACTIVE` `SELL` 的成交价与精确 `vsLastSellPct`；撤销该卖出后自动回退到上一笔有效卖出或 `null`；无有效卖出时返回 `null`。
- **AC2（SSE 实时派生）**：实时行情推流更新 `lastPrice` 时，前端活动仓位列表与详情页汇总中的 `vsLastSellPct` 自动按 `BigInt` 精确重算，与后端公式一致。
- **AC3（活动仓位筛选与搜索）**：`全部 / 低批盈利 / 低于上卖 / 浮亏仓位` 四个标签角标计数准确、点击过滤结果准确；输入代码或名称可即时过滤；紧凑模式按钮可切换行密度。
- **AC4（五维正反排序）**：默认按「现价（当日涨跌幅）」降序；点击「总市值」「浮盈」「现价」「低批」「上卖」均可正反切换排序，且缺失值在任意维度和方向下始终排在末尾。
- **AC5（双端对齐与零溢出）**：PC 端（`>= 1280px` 与 `>= 900px`）与移动端（`360x780`、`390x844`）均使用同一三列行结构，移动端满足 `document.documentElement.scrollWidth <= window.innerWidth`；无卖出显示 `暂无卖出` 与 `—`。
- **AC6（PC 右栏详情联动与独立详情页）**：PC 端首页右侧直接渲染当前选中仓位的完整详情面板，点击左侧不同仓位可即时切换且旧请求不会串数据；独立详情页 `/security/:market/:symbol` 在 PC 端与移动端均展示“上次卖出价”及相对涨跌幅，且 PC 端左侧切换栏与首页活动仓位对齐。
- **AC7（质量门禁）**：后端 `pytest`、前端 `type-check`、`build` 以及更新后的 Playwright E2E（含 PC 端与移动端）全部通过。
