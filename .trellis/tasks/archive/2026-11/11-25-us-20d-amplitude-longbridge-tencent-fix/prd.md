# 美股 20 日平均振幅接入长桥日 K 主源并修复腾讯备源

## 背景与问题

在已上线的个股近 20 个已收盘交易日平均振幅功能中，美股持仓在实际环境下无法稳定展示 20 日振幅（前端持续显示 `—`），主要原因有三点：

1. **未接入已配置的长桥数据源**：当系统配置 `quote.provider = longbridge` 时，实时报价与推送已走长桥通道，但 20 日振幅服务仍仅依赖东方财富与腾讯两个公网免费接口。
2. **东方财富日 K 接口易被远端断连**：`push2his.eastmoney.com` 在当前网络环境下直接触发 `RemoteDisconnected`，导致主源不可用并回退至腾讯备源。
3. **腾讯美股日 K 备源缺少交易所后缀**：当前构造的腾讯请求参数为 `us{CODE}`（未附带 `.OQ` / `.N` / `.AM` 交易所后缀），腾讯接口不返回历史 `qfqday` 序列，仅返回当日 1 条记录（部分老股夹杂 `2011-06-02` 历史占位行），导致绝大多数美股解析为空（`null`），少数标的还会因跨年占位行计算出严重失真的振幅值。

## 需求范围（In Scope）

### R1. 长桥日 K 主源接入（复用长桥配置与连接）
- 当后端配置 `quote_provider == "longbridge"` 时，近 20 日平均振幅优先通过长桥 `QuoteContext` 日 K 接口拉取受支持市场（美股 `US` 及沪深 A 股 `SH`/`SZ`）的历史日 K 线。
- 复用现有 `LongbridgeQuoteProvider` 的凭据与 `QuoteContext` 实例，不新增额外配置项，也不在模块导入或 `mock` / `cache` 模式下发起网络请求。
- 北交所（`BJ`）及场外基金（`OF`）等长桥不支持的市场平滑走原有路由或跳过策略，互不影响。
- 长桥拉取失败、超时或返回空数据时，自动降级回退到既有备源（东财 / 腾讯），不阻断 `GET /api/v1/dashboard`。

### R2. 修复腾讯美股日 K 备源
- 腾讯美股日 K 请求按交易所后缀（`.OQ` 纳斯达克 / `.N` 纽交所 / `.AM` 美交所/Arca）准确构造参数，优先结合东方财富市场码解析结果映射对应后缀（`105 -> .OQ`、`106 -> .N`、`107 -> .AM`），未命中时按顺序探测候选后缀，确保返回完整历史 `qfqday` 序列。
- 对相邻交易日间隔异常的占位行（如 `2011-06-02` 与近期日期直接相邻）进行防护，禁止用多年以前的收盘价充当昨日收盘价计算振幅。
- 美股在东财与腾讯之间保持清晰的容错与回退，避免在 `eastmoney` 模式下美股仍大面积返回 `null`。

### R3. 缓存、冷却与口径一致性
- 保持既有统计口径不变：单日振幅 `(最高价 - 最低价) / 昨收 × 100%`，严格排除当日盘中未收盘 K 线，最多取最近 20 个已收盘交易日算术均值，持久化写入 `security_daily_metrics`。
- 美股在 `longbridge` 模式下仅取常规交易时段日 K（排除盘前/盘后扩展时段对日内高低价的干扰），采用前复权口径以避免除权/拆股日昨收跳变导致振幅失真。
- 保持 `GET /api/v1/dashboard` 返回结构与前端展示不变，无需修改数据库表结构或前端代码。

## 范围外（Out of Scope）

- 不修改 `security_daily_metrics` 表结构与 Alembic 迁移。
- 不修改前端 `ActivePositionList.vue` 或 `DashboardPosition` API 契约。
- 不新增用户可见的配置项或环境变量（完全复用现有 `quote.provider` 与 `quote.longbridge.*` 配置）。
- 不为场外基金（`OF`）计算日内振幅。

## 验收标准

1. **长桥主源**：配置 `quote_provider == "longbridge"` 时，美股（如 `US:AAPL`、`US:VOO`）与沪深 A 股（`SH`/`SZ`）优先通过长桥日 K 计算近 20 个已收盘交易日平均振幅，返回 `provider == "longbridge-kline"`，严格排除当日未收盘 K 线；长桥异常时自动回退至东财/腾讯备源。
2. **腾讯美股备源修复**：不启用长桥或长桥失败、且东财不可用时，腾讯美股日 K 能通过正确交易所后缀（`.OQ` / `.N` / `.AM`）拉取完整历史 `qfqday` 序列并准确计算 20 日平均振幅；当上游仅返回单日或夹杂多年占位行时，不会算出失真的跨年振幅。
3. **测试隔离与离线安全**：所有自动化测试均通过依赖注入（mock `QuoteContext` / `transport` / `now`）完成，不依赖公网、不触碰本地 `ledger.db`；`mock` 模式与 `mode="cache"` 下零网络请求。
4. **质量门禁**：后端 `pytest` 全部通过，且新增单元测试覆盖长桥日 K 主源、长桥失败回退、腾讯美股后缀映射与探测、占位行防护及路由装配逻辑。
