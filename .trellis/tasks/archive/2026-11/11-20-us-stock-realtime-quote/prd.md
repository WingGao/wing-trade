# 支持美股和实时行情

## 目标（Goal）

扩展个人交易账本，完整支持美股（`US`）资产的日常管理（多账户切换、USD 账户创建、碎股与手续费记账、流水与复盘）以及零配置公开实时行情能力（覆盖美股常规盘及盘前/盘后扩展时段，轮询体验与 A 股一致）。

## 已确认产品决策

1. **美股行情源**：采用零配置公开数据源（沿用东方财富公开接口，无需 API Key，国内直连可用）。
2. **盘前 / 盘后时段**：支持美股盘前（Pre-market，美东 04:00–09:30）与盘后（After-hours，美东 16:00–20:00）行情获取、估值计算及界面时段标识。
3. **实时更新形态**：与 A 股保持一致，沿用现有 HTTP 定时短轮询策略（总览活跃时段 10 秒 / 休市 60 秒；详情页 3 秒轮询 + 后端 2.5 秒防抖），不引入 SSE/WebSocket。
4. **美股账户与页面范围**：一并补齐全局账户切换、USD 账户管理、总览/流水/复盘多账户多币种展示，以及美股碎股（小数股数）与手续费录入/展示适配。

## 需求（Requirements）

### R-01 美股批量实时行情与盘前/盘后支持
- 系统在 `QUOTE_PROVIDER=eastmoney` 默认配置下，支持自动批量刷新 `US:*` 证券行情，且与 A 股（`SH/SZ/BJ`）、场外基金（`OF`）在组合行情源中互不阻塞、独立容错。
- 自动解析并缓存美股对应的东方财富交易所编号（`105/106/107`），不依赖用户手工选择交易所。
- 在美股盘前（美东 04:00–09:30）与盘后（美东 16:00–20:00）时段：
  - 若上游提供有效盘前/盘后成交价，将其作为当前参考估值价并明确标注时段状态（`pre` 盘前 / `post` 盘后）；若暂无扩展时段成交，则回退展示有效收盘/最新价。
  - 所有价格、涨跌幅均使用 `Decimal` 精确解析，失败时保留最后有效缓存并标记过期，不得伪造零值，不得用过期行情触发止盈提醒。

### R-02 美股扩展交易日历与 Dashboard 时段感知
- `USTradingCalendar` 区分四个美股时段：`pre`（盘前 04:00–09:30 ET）、`regular`（盘中 09:30–16:00 ET）、`post`（盘后 16:00–20:00 ET）、`closed`（休市）。
- 美股活跃时段（`pre`、`regular`、`post`）内 `is_session_open` 返回 `True`，缓存新鲜度与总览轮询频率与 A 股一致（10 秒轮询 / 10 秒活跃 TTL；休市 60 秒轮询 / 1 小时 TTL）。
- `DashboardService.build()` 按账户币种/所属市场选择对应交易日历：`USD` 账户使用美股日历，`CNY` 账户保持 A 股日历，准确返回 `marketSessionOpen`、`marketSession` 与 `pollAfterSeconds`。

### R-03 美股分时曲线修复与盘前/盘后覆盖
- 修复美股日内分时拉取：开启盘前/盘后扩展分时数据，共享稳定的美股市场码解析能力。
- 修正美股分时时间戳的时区解析与美股交易日归属逻辑，确保北京时间午夜（00:00–09:00）不会截断美股盘中或盘后曲线。
- 详情页美股分时保持与 A 股一致的 3 秒轮询机制，并展示当前美股时段标签（盘前 / 实时 / 盘后 / 已过期）。

### R-04 全局多账户切换与 USD 账户管理
- 应用顶栏（桌面端与移动端）提供全局账户切换器与“新建账户”入口，支持创建 `CNY` 或 `USD` 账户（含账户名称、币种、券商选填）。
- 侧边栏与页面文案去除“A 股交易账本”单一市场限定，改为通用个人交易账本表述。
- 总览页（`DashboardPage`）跟随当前选中账户加载持仓、估值与行情，并在快速记账搜索到美股但尚无 USD 账户时，提供一键新建 USD 账户的引导。

### R-05 交易流水与复盘页多账户多币种适配
- 交易流水页（`TradesPage`）支持按账户筛选（默认跟随当前选中账户，也可切换“全部账户”），成交价格、费用等金额按各自交易币种（`$` / `¥`）正确格式化。
- 复盘分析页（`AnalyticsPage`）跟随当前选中账户拉取 `/api/v1/analytics/summary` 与 `/api/v1/cycles`，修复硬编码 `¥` 问题，按账户币种格式化金额，并在交易周期表中展示可读的证券代码与名称。

### R-06 美股碎股（小数股数）与手续费适配
- 数量展示规则：A 股保持整数；场外基金保持 2–4 位小数（单位“份”）；美股支持最多 4 位有效小数（整数时显示整数、碎股时保留实际小数位，不四舍五入截断，单位“股”）。
- 买入弹窗（`BuyTradeDialog`）与卖出抽屉（`SellMatchDrawer`）：
  - 美股数量输入支持小数（`inputmode="decimal"`）并给出碎股输入提示。
  - 补齐美股常用费用录入（买入支持佣金、其他/平台费；卖出支持佣金、其他/平台费，并同步参与卖出预览与实盘记账）。

## 验收标准（Acceptance Criteria）

- [x] **美股批量行情**：后端单测与集成测试验证 `EastmoneyUSQuoteProvider` 支持 `105/106/107` 市场码解析、常规盘与盘前/盘后快照解析、Decimal 精度、单批失败回退及与 A 股/基金在 `CompositeQuoteProvider` 中互不干扰。
- [x] **美股日历与 Dashboard**：单元测试验证 `USTradingCalendar` 在美东盘前、盘中、盘后、休市（含周末与夏/冬令时）的时段判断；集成测试验证 `USD` 账户调用 `/api/v1/dashboard` 在美股活跃时段返回 `marketSessionOpen=true`、`pollAfterSeconds=10` 及正确的 `marketSession`。
- [x] **美股分时曲线**：单元测试与 API 测试验证美股分时包含盘前/盘后点、跨北京时间午夜仍归属同一美股交易日、并在失败时降级为过期缓存。
- [x] **多账户与 USD 账户管理**：前端可新建 USD 账户并在桌面端与移动端全局切换 CNY/USD 账户；总览、交易流水、复盘页数据与币种符号（`$` / `¥`）随账户同步更新。
- [x] **碎股与手续费**：美股可录入并正确展示小数股数（如 `0.25`、`1.5` 股）与买卖佣金/其他费用，卖出预览与记账包含费用且后端账务精度无损。
- [x] **质量门禁**：后端全量 `pytest`、前端 `type-check` / `build` 通过；不删除或清空本地 `ledger.db`。

## 范围外（Out of Scope）

- 跨币种汇率换算（CNY 与 USD 资产自动折合汇总）。
- 卖空、期权、融资融券、股息/拆股等公司行动自动化处理。
- 收费或需申请 API Key 的商业行情源接入。
- 服务端推送（SSE / WebSocket）重构。
